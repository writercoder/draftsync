# Demo: Five Sonnets

A draftsync example project: five of Shakespeare's sonnets (18, 29, 73,
116, 130), one per chapter file. Public domain; text from
[Project Gutenberg ebook #1041](https://www.gutenberg.org/ebooks/1041).

Good for demoing **editions**: a "Fair Youth" edition (18, 29, 73, 116)
against the full selection (adding 130, from the Dark Lady sequence).
